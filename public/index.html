    Scan settings

    Admin password

    In demo mode there's no password. When you run Aisty Signal for real, you create one on first start and can change it here.

    This password is set by SIGNAL_ADMIN_PASSWORD in .env, so it can't be changed here.

    Your data

    Results and connection details are stored on this server in data/ and nowhere else. Credentials are encrypted. Aisty Signal never reads email bodies, and it sends nothing to Aisty or any third party.

    Aisty Signal is free, open-source software (MIT). It runs on your own infrastructure, and your data stays there.
